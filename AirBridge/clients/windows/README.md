# AirBridge — Windows Companion Client

Zero-install, ultra-lightweight Windows companion client for **AirBridge**.

## Features
- **Seamless Universal Clipboard:**
  - Copy on Mac (`Cmd + C`) ➔ Paste on Windows (`Ctrl + V`) immediately!
  - Copy on Windows (`Ctrl + C`) ➔ Paste on Mac (`Cmd + V`) immediately!
- **100% Offline & Private:**
  - Connects directly to your Mac over Wi-Fi / Hotspot.
  - Secured with your 4-digit pairing PIN.

## How to Run on Windows
1. Make sure your Windows PC and Mac are on the same Wi-Fi or Phone Hotspot.
2. Double-click `run_airbridge.bat` (or run `python airbridge_tray.py`).
3. Enter the Mac IP address and the 4-digit PIN shown on your Mac Menu Bar.
4. Done! You can now copy and paste seamlessly between Mac and Windows!
